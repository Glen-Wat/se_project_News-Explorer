# News Explorer

News Explorer is a modern web application that allows users to search for news articles, save them to a personal account, and view saved articles. The app features user authentication, responsive design, and keyword-based article management.

---

## Demo

Live demo: [**News Explorer Live**](https://glen-wat.github.io/se_project_News-Explorer/)

---

## Features

- Search for news articles by keyword
- Save articles to your personal account
- View and manage saved articles
- User authentication (Sign Up / Sign In)
- Responsive design for desktop and mobile
- Keyword summary for saved articles

---

## Technologies

**Frontend:** React, Vite, Tailwind CSS, HTML, CSS  
**Backend:** Node.js, Express, MongoDB, REST API  
**Tools:** Git, GitHub, Postman, React Router, Context API

---

## Installation

1. Clone the repo:

```bash
git clone https://github.com/glen-wat/news-explorer.git
cd news-explorer
npm install
npm run dev

```
